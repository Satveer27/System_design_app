# FPL Analytics

A free, non-commercial website for Fantasy Premier League managers: player and club analytics,
Plans built on a drag-and-drop pitch, shareable tier lists and, in a later phase, machine-learning
predictions with a public scorecard of how they performed.

Work is planned in the [PRD](https://github.com/Satveer27/System_design_app/issues/2) and its
sub-issues; decisions are in `docs/adr/` and terms in `GLOSSARY.md`.

Data comes from Fantasy Premier League. This project is not affiliated with or endorsed by the
Premier League.
